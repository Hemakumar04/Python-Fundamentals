# Python-Fundamentals
01_Covers core Python fundamentals, from basic syntax up to functions.

Section 1 – Basic Concepts: Variables, Data Types, Type Casting, Operators, Input & Output, Comments

Section 2 – Control Flow: if / elif / else, for loop, while loop, break, continue, pass

Section 3 – Collections: List, Tuple, Set, Dictionary, List Comprehension, Dictionary Comprehension

Section 4 – Functions: Function basics, Arguments, Default Arguments, Keyword Arguments, Variable-Length Arguments (*args, **kwargs), Lambda Functions, Recursive Functions

02_Advanced_Python_and_Builtins.ipynb

Covers advanced Python language features and commonly used built-in functions.

Section 1 – Advanced Python: Iterators, Generators, yield, Decorators, Closures, global & nonlocal, Modules, Packages, Virtual Environments, Type Hinting

Section 2 – Built-in Functions: map(), filter(), zip(), enumerate(), sorted(), any(), all(), isinstance(), id()

03_OOP_Concepts.ipynb

Covers Object-Oriented Programming principles in Python, from the basics through inheritance, polymorphism, and design patterns.

Section 1 – Classes, Objects and Attributes: Class, Object, Constructor (__init__), Instance Variables, Class Variables

Section 2 – Methods: Instance Methods, Static Methods, Class Methods, Properties (@property)

Section 3 – Encapsulation and Abstraction: Encapsulation, Abstraction

Section 4 – Inheritance: Inheritance, Multiple Inheritance, Multilevel Inheritance, Hierarchical Inheritance

Section 5 – Polymorphism: Polymorphism, Method Overriding, Method Overloading (Python Approach)

Section 6 – Class Relationships: Composition, Aggregation, Association

Section 7 – Magic Methods: Magic (Dunder) Methods, super(), __str__(), __repr__(), __len__()

Section 8 – Bonus Topics: Dataclasses, Singleton Pattern
