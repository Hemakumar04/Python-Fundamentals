# Python-Fundamentals
Covers core Python fundamentals, from basic syntax up to functions.

Section 1 – Basic Concepts: Variables, Data Types, Type Casting, Operators, Input & Output, Comments

Section 2 – Control Flow: if / elif / else, for loop, while loop, break, continue, pass

Section 3 – Collections: List, Tuple, Set, Dictionary, List Comprehension, Dictionary Comprehension

Section 4 – Functions: Function basics, Arguments, Default Arguments, Keyword Arguments, Variable-Length Arguments (*args, **kwargs), Lambda Functions, Recursive Functions
